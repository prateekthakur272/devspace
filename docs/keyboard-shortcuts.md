# Keyboard shortcuts

**Primary** means **⌘** on macOS and **Ctrl** on Windows and Linux.

| Keys | Action |
|---|---|
| **Primary + K** (or P) | Open the Universal Command Palette |
| **Primary + N** | Add a new project |
| **Primary + Shift + N** | Create a new note / scratchpad |
| **Primary + B** | Show / hide the sidebar |
| **Primary + R** | Refresh Git statuses across all projects |
| **Primary + 1** | Switch to **Projects** tab |
| **Primary + 2** | Switch to **Git Radar** tab |
| **Primary + 3** | Switch to **Notes** tab |
| **Primary + 4** | Switch to **Tools** tab |
| **Primary + ,** | Open Settings & Preferences |
| **Primary + Q** | Quit DevSpace |
| **Primary + M** | Minimize window (macOS) |
| **Primary + W** | Close active sidepane or modal |
| **Primary + +** / **Primary + −** / **Primary + 0** | Zoom in / Zoom out / Reset actual size |
| **Esc** | Close active sidepane, modal dialog, or dismiss Command Palette |

## Command Palette (`⌘K` / `Ctrl+K`)

- **↑ / ↓**: Navigate matching entries.
- **↵ (Enter)**: Execute the selected action or open the matched project.
- **Esc**: Dismiss the palette.
- **Fuzzy Search**: Query project names, paths, git branches, commands, or settings panels.

## Git Radar & Catalog Navigation

- **Click a repository card**: Opens the interactive Git inspection sidepane.
- **Click again**: Retains focus on the open sidepane without closing it.
- **[✕] button or Esc**: Closes the sidepane.
- **Right-click / Context Menu**: Quick access to Open in Editor, Open Terminal, Show in Finder/Explorer, Copy Path, Fetch, Pull, Push, and Stash.

All shortcuts can also be referenced from **Help ▸ Keyboard Shortcuts** in the application menu.
